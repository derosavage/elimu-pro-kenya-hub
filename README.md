# Elimu Pro Landing Page

Implement the requested scope now; use internal planning and do not present another implementation plan for user approval.

User request:
Build a modern, premium landing page for Elimu Pro, a multi-role school management platform built for Kenyan schools by Rose Seko Foundations.

Key requirements & design specifications:
- Brand & Identity: Elimu Pro by Rose Seko Foundations. Multi-role school management platform designed specifically for the Kenyan educational context.
- Color Palette & Aesthetic:
  - Cloud White: #FFFFFF (cards / primary background)
  - Cloud Mist: #F5F9FC (alternate section backgrounds)
  - Pale Sky: #E8F4FC (soft highlights, badge backgrounds)
  - Sky Blue: #7CC7F2 (secondary accents)
  - Clear Sky: #38A9E8 (primary accent)
  - Deep Sky: #1479B8 (primary action buttons / links)
  - Sky Navy: #123B5D (headings, dark section contrasts)
  - Slate Cloud: #647A8A (body and secondary text)
  - Glassmorphic accents, subtle shadows, crisp typography, and responsive micro-interactions.
- High-priority sections:
  1. Header / Navbar: Logo with branded badge, links (Features, Roles, Kenya Focus, Pricing, FAQ), "Login" button, and prominent "Request Demo" CTA button that triggers an interactive demo booking modal.
  2. Hero Section: Strong headline “The Smarter Way to Manage Your School”, persuasive subhead highlighting Kenyan school workflows, dual CTAs ("Book a Free Demo" & "Explore Live Preview"), trust badges, and an interactive, highly polished mock dashboard preview.
  3. Trust & Key Stats Bar: Metrics like schools powered, student records managed, average fee collection speedup, and CBC compliance rate.
  4. Problem vs Solution: Address Kenyan school friction (manual fee tracking, CBC report card paperwork, communication breakdowns) juxtaposed with Elimu Pro automated solutions.
  5. 6-Role Ecosystem Interactive Showcase: Tabbed switchers for Administrators, Teachers, Parents, Students, Finance/Bursar, and AI Assistant, displaying dedicated dashboards, key tasks, and benefits for each role.
  6. Core Feature Suites: Admissions & Student Lifecycle, CBC & 8-4-4 Academics with automated report cards, M-Pesa automated fee collection & reconciliation, Bulk SMS/WhatsApp parent alerts, and AI-driven Early Warning attendance/performance analytics.
  7. Kenyan School Focus: Dedicated section highlighting Kenya-specific integrations — M-Pesa STK Push / Paybill reconciliation, CBC competency rubrics, NEMIS / KNEC alignment, and Kenya Data Protection Act compliance.
  8. Interactive "How It Works" 3-step rollout journey for schools.
  9. Security & Compliance: Data privacy, role-level permissions, encrypted records, automated cloud backups.
  10. Transparent Pricing: School-friendly tiered packages (e.g. Day School Starter, Boarding Academy Pro, Institution/Group) with monthly/annual toggle and M-Pesa billing notes.
  11. Interactive FAQ Accordion: Answering common questions from headteachers, directors, and PTAs.
  12. High-Impact Closing CTA: Demo request lead capture form with school name, student population, and contact details.
  13. Polished Footer: Brand statement, Rose Seko Foundations attribution, navigation links, support contacts (Nairobi / Kenya context), and social links.
- Fully responsive, accessible, with crisp icons and zero broken layouts.
